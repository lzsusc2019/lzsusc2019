**在做的事**

- **平台架构** — 定时任务调度平台、配置中心、安全服务中心的从 0 到 1；关注大规模系统的平滑演进：存量系统零故障迁移、能力灰度上线、上下游链路一致性
- **AI Agent 工程化** — 智能体用户面中台，涉及 Agent Runtime、分布式有状态沙箱、Checkpoint 持久化与断点续传、Skill/MCP 热加载
